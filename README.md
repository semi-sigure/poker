# ♠ Poker Night

仲間内4人で遊ぶ、ブラウザのテキサスホールデム(ノーリミット)です。ログインやアカウントは不要で、URLを開いて自分のキャラクターを選ぶだけで入れます。

- 固定メンバー4人(よしき / monmemono / ネギおじさん / ひろ君)。ネギおじさんがホスト
- Node.js + WebSocket の自前サーバーで動きます。Claude は不要です
- ディーラーはいません。配牌・ポット計算・サイドポットはサーバーが自動で行います
- テキストチャットはありません

## 遊び方

1. ページを開き、ログイン画面のイラストから自分のキャラクターをクリックして入室します。
2. 全員そろったら、ホストが「ゲーム開始」を押します。席順は開始時にランダムです。
3. 自分の番に、フォールド / チェック / コール / レイズ / オールインを選びます。

再読み込みしても同じ席に戻れます。

## ルール

### チップとブラインド
開始スタックは5000チップ(250BB)です。ブラインドは12分ごとに上がり、アンティは最初から全員が払います。

| レベル | 経過時間 | SB / BB | アンティ |
| --- | --- | --- | --- |
| 1 | 0〜12分 | 10 / 20 | 5 |
| 2 | 12〜24分 | 20 / 40 | 10 |
| 3 | 24〜36分 | 30 / 60 | 15 |
| 4 | 36〜48分 | 40 / 80 | 20 |
| 5 | 48〜60分 | 50 / 100 | 25 |

### 終了
- ゲーム開始から60分たつと自動で終了します。そのとき進行中のハンドは最後まで行い、そのあと結果発表です。
- チップを持つ人が1人だけになったら、その人の優勝で終了します。
- 順位はチップ額で決まります。

### 脱落と観戦
チップが0になると脱落で、リエントリー(再参加)はできません。脱落後は観戦できます(他の人の手札は見えません)。

### 時間制限と離席
- 1回の持ち時間は25秒です。切れるとチェック、できなければフォールドになります。
- 2回続けて時間切れになると離席扱いになります。「離席する」ボタンで自分から離席もできます。
- 離席中でも、アンティ・SB・BB は毎ハンド徴収され、ボタンも回ります。手番は自動でチェックかフォールドになります。

## 画面の見どころ

- 手元に現在の役が表示され、ショーダウンでは役を作るカード(水色)と残りのベスト5枚(金色)を色分けします
- オールインのカットイン、ヘッズアップ時のVS演出、獲得ポットの大きさに応じた演出
- スタックが2000以下で傷だらけ、8000以上で勝ち誇った差分画像に切り替わります
- BGM はログイン画面、通常、1人脱落、2人脱落、オールインで切り替わります。効果音つき
- レイズは 1/3・1/2・2/3・7割・ポット・3倍のボタン、スライダー、数字入力で指定できます

## 動かし方

```
npm install
npm start
```

`http://localhost:3000` を開きます。ポートは環境変数 `PORT` で変えられます(Node.js 18 以上)。

### Render で公開する(無料)

1. このリポジトリを GitHub に置きます。
2. Render で New → Web Service を選び、このリポジトリを指定します。
3. Build Command は `npm install`、Start Command は `npm start` にします。
4. 発行された URL を友達に共有します。無料プランは15分アクセスがないと止まり、次のアクセスで数十秒かけて起き上がります。

ファイルを更新したらコミットすれば、Render が自動で再デプロイします。ブラウザは Ctrl+F5 で読み込み直してください。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `server.js` | サーバー。配牌・ベット処理・ショーダウン・ブラインド上昇・自動終了など、ゲームの進行と判定をすべて行う |
| `index.html` | 画面と演出(1ファイル) |
| `img/` | キャラクター画像(通常 / `_low` 傷つき / `_high` 勝利)と、背景・テーブル画像 |
| `audio/` | BGM(ログイン、通常、1人脱落、2人脱落、オールイン) |

手札はサーバーだけが持ち、他のプレイヤーには伏せたまま送られます。ショーダウンで公開される札だけが全員に見えます。
